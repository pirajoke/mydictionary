Контуры внедрения и отсутствующие артефакты

Что можно автоматизировать уже сейчас и какие минимальные документы нужны, чтобы изменения не ломали production-контур.

7a. Контуры автоматизации

Единый язык интерфейса

P0

Зачем: пользователь не должен попадать из французского урока в русскую ошибку, AI или оплату.

Сейчас: onboarding, home и active learning покрыты; legacy/AI/Stars поверхности требуют отдельного locale inventory.

Автоматизировать
locale persistence, coverage tests, compatible-pair fallback.
Оставить человеку
тон, юридическую формулировку billing и культурную проверку.
Риск: learning content и интерфейс нельзя смешивать: русский перевод слова может быть корректным пользовательским выбором.

Восстановить публичный маршрут

P0

Зачем: admin/login и health должны быть доступны через ожидаемый домен.

Сейчас: origin healthy; connector отсутствует; Cloudflare 1033.

Автоматизировать
service health, connector health, public probes, rollback.
Оставить человеку
tunnel token enrollment и DNS ownership.
Риск: bearer token нельзя помещать в CLI, env, compose или журнал.

Наблюдаемое удержание

P1

Зачем: понять, возвращается ли ученик после первой ценности.

Сейчас: public cohort 1; D1/D7 eligible 0.

Автоматизировать
daily aggregate D1/D7, N, freshness and health.
Оставить человеку
этичный набор cohort и решение только при N≥10.
Риск: проценты маленькой выборки создают ложную уверенность.

Восстановление вне VPS

P1

Зачем: локальный dump не защищает от потери или компрометации хоста.

Сейчас: latest dump verified; 0 encrypted objects and restore receipts.

Автоматизировать
age encryption, immutable upload, checksum and receipt.
Оставить человеку
backend choice, key custody и isolated restore approval.
Риск: private age identity не должна находиться на production.

Stars test lane

P1

Зачем: проверить деньги без риска для production.

Сейчас: 0 receipts и checkout off.

Автоматизировать
preflight, duplicate, restart, reconcile.
Оставить человеку
test account, seller terms, refund decision.
Риск: тестовые credentials нельзя смешать с production.

Визуальный пилот карточек

P2

Зачем: усилить запоминание после исправления базового UX.

Сейчас: 0 word images / 901 entries.

Автоматизировать
черновики, размеры, Telegram file_id cache.
Оставить человеку
семантику и культурную корректность.
Риск: неоднозначная картинка учит неверному значению.

7b. Отсутствующие операционные артефакты

Cloudflare acceptance receiptСимптом: origin 200, public 1033.Минимум: connector active, public health/login, rollback proof.КРИТИЧНО
Off-site recovery receiptСимптом: нет remote/key custodian/restore proof.Минимум: immutable `.age` object + separate-host restore receipt.КРИТИЧНО
Current-runtime AI receiptСимптом: OVH DB содержит 0 completed calls.Минимум: один bounded call + settled usage/cost aggregate.ВЫСОКИЙ
Stars test receiptСимптом: seller/test credentials/receipt отсутствуют.Минимум: isolated purchase, duplicate, restart, reconcile, refund, cancel.ВЫСОКИЙ
Token rotation receiptСимптом: 6,380 historical matches при нулевом новом leakage.Минимум: BotFather rotation + replacement heartbeat; cleanup отдельно.ВЫСОКИЙ

Текущая ветка закрывает 18/18 базовых управленческих артефактов: NSM, OMTM, OKR, weekly check-in, AGENTS, prompt library, runbooks, запреты, eval, SSOT, glossary, freshness, history, ADR/decision log, ownership, escalation и incident log. Внешние receipts выше нельзя сгенерировать без реального действия.
