Контуры внедрения и отсутствующие артефакты

Что можно автоматизировать уже сейчас и какие минимальные документы нужны, чтобы изменения не ломали production-контур.

7a. Контуры автоматизации

Единый язык интерфейса

P0

Зачем: пользователь не должен читать французское меню и русскую карточку.

Сейчас: 86 keys / 8 locales; home-путь и curated meanings покрыты, 302 кириллические строки остаются proxy для следующего inventory.

Автоматизировать
locale persistence, compatible-pair filter, coverage tests, legacy fallback.
Оставить человеку
тон, культурную проверку и приоритет следующих экранов.
Риск: нельзя выдавать отсутствующий перевод; legacy ja/vi безопасно сохраняют русский смысл.

Правдивый production SSOT

P0

Зачем: любой deploy должен попадать на OVH, а не в исторический Mac mini.

Сейчас: runtime и репозиторий расходятся на 1 host model.

Автоматизировать
active SHA, DB revision, backup age, service health.
Оставить человеку
доступ, deploy approval, rollback decision.
Риск: документировать команды без подтверждённого Compose-контракта нельзя.

Наблюдаемый пилот

P1

Зачем: решить, возвращает ли продукт ученика.

Сейчас: cohort 3; D7 eligible 0.

Автоматизировать
daily aggregate D1/D7, N, freshness, alert.
Оставить человеку
набор cohort и решение при N≥10.
Риск: проценты маленькой выборки создают ложную уверенность.

Восстановление вне VPS

P1

Зачем: локальные dumps не защищают от потери VPS.

Сейчас: 2 verified dumps; 0 recovery-host receipts.

Автоматизировать
age encryption, immutable upload, checksum.
Оставить человеку
key custody и отдельный restore approval.
Риск: identity не должна находиться на production.

Stars test lane

P1

Зачем: проверить деньги без риска для production.

Сейчас: 0 receipts и checkout off.

Автоматизировать
preflight, duplicate, restart, reconcile.
Оставить человеку
test account, seller terms, refund decision.
Риск: тестовые credentials нельзя смешать с production.

Визуальный пилот карточек

P2

Зачем: усилить запоминание после исправления базового UX.

Сейчас: 0 word images / 901 entries.

Автоматизировать
черновики, размеры, Telegram file_id cache.
Оставить человеку
семантику и культурную корректность.
Риск: неоднозначная картинка учит неверному значению.
