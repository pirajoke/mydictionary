# Условия тестирования Telegram Stars

Версия: `stars-test-2026-08-07`

Эти условия применяются только к отдельному боту и аккаунту в тестовой среде
Telegram. Тестовые Stars, тестовые AI-кредиты и тестовые подписки не имеют
денежной стоимости, не дают право на выплату и не переносятся в production.

Тестовый платёж используется для проверки счёта, `pre_checkout_query`,
`successful_payment`, идемпотентного начисления, отмены подписки, сверки и
полного тестового возврата. Начисление выполняется только после подтверждённого
`successful_payment` от Telegram test environment.

Данные тестовой среды хранятся отдельно от production и могут быть удалены
после завершения проверки. Для вопросов по тестовой операции используй контакт
поддержки, показанный командой `/paysupport` тестового бота.
